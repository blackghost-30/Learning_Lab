# 第八讲：模块化布局-预布局

本节课的内容是把一些大的器件先放进去，实现预布局，预布局的总原则是先大后小。

- 打开飞线，先将大的器件摆进去；
- 根据飞线的走向调整大器件的方向，方便后续走线；
- 先放FPGA——>再放DDR3——>摆DCDC芯片进去——>将HDMI模块全部放进去——>POWER部分可最后再放；
- 放MCU和晶振进去——>Flash和晶振拉进去——>数码管放进去；
- 最后处理电源，可以将5V网络单独给一个颜色，然后把DCDC芯片放进去；

# 第八讲（4）：DDR模块布局

## 1.DDR布局要点

- DDR布线需要注意一下要点
  - DDR一定要靠近CPU摆放，当DDR数量大于2时，摆放的位置要相对于CPU对称，一般是放同一边但相对于CPU中心对称；
  - 对应端接电阻，需要分串联端接和并联端接，其中串联端接放置到CPU端，并联端接放到DDR端；
  - 端接电阻的主要作用是硬件上的阻抗匹配，但是在画PCB时还是要考虑阻抗匹配；
  - 对于T型结构，并联电阻放在DDR端的第一个T点处，若是菊花链拓扑，则放到最后一个DDR后面，本次项目属于只有一个放最后即可；
  - Vref电容和电源的滤波电容都靠近引脚放置即可；

![DDR布线要点](.\img\第八讲（4）：DDR模块布局\DDR布局要点.png)

# 第十讲：PCB 的层数分析以及叠层设置

## 1.多层板如何去叠层？

确定多层板层数需要综合考虑以下因素：

- **单板电源、地的种类**
- **信号密度**
- **板级工作频率**
- **特殊布线要求的信号数量**
- **生产成本要求**

## 2.六层板常见的几种叠层方式

### 2.1 方案一

| 序号 | 名称      |
| ---- | --------- |
| 1    | 顶层      |
| 2    | GND 02    |
| 3    | Signal 03 |
| 4    | Power 04  |
| 5    | GND 05    |
| 6    | 底层      |

**叠层结构：** 顶层 — GND 02 — Signal 03 — Power 04 — GND 05 — 底层

**优点：**

- 电源层和地层紧密耦合；
- 每个信号层都与内电层直接相邻，与其他信号层均有有效隔离，不易发生串扰。

---

### 2.2 方案二

| 序号 | 名称      |
| ---- | --------- |
| 1    | 顶层      |
| 2    | GND 02    |
| 3    | Signal 03 |
| 4    | Signal 04 |
| 5    | Power 05  |
| 6    | 底层      |

**叠层结构：** 顶层 — GND 02 — Signal 03 — Signal 04 — Power 05 — 底层

**优点：**
- 采用了 2 个信号层和两层内部电源/地层，具有较多的信号层，有利于元器件之间的布线工作。

**缺点：**
- 电源层和地线层分割较远，没有充分耦合；
- 信号层 Signal 03 和 Signal 04 之间相邻，信号完整性不好，容易发生串扰，布线时需错开布线。

---

### 2.3 方案三

| 序号 | 名称      |
| ---- | --------- |
| 1    | 顶层      |
| 2    | GND 02    |
| 3    | Signal 03 |
| 4    | GND 04    |
| 5    | Power 05  |
| 6    | 底层      |

**叠层结构：** 顶层 — GND 02 — Signal 03 — GND 04 — Power 05 — 底层

**优点：**
- 电源层和地耦合充分；
- 信号层与内电层直接相邻，与其他信号层均有有效隔离，不易发生串扰；
- Signal 03 和两个内电层（GND 和 Power）相邻，可用来传输高速信号，两内层可有效屏蔽外界对 Signal 03 的干扰。

**缺点：**
- 底层器件不能参考 GND。

---

### 2.4 方案四

| 序号 | 名称      |
| ---- | --------- |
| 1    | 顶层      |
| 2    | Signal 02 |
| 3    | GND 03    |
| 4    | Power 04  |
| 5    | Signal 05 |
| 6    | 底层      |

**叠层结构：** 顶层 — Signal 02 — GND 03 — Power 04 — Signal 05 — 底层

**说明：**
- 此方案在优先考虑信号层布线的情况下采用，信号层与电源/地层交替排布；
- 可通过调整层间距来减小层间干扰；
- 当因成本等因素限制层数选择时，可酌情选用不同的叠层方案。

## 3.方案对比总结

| 方案   | 信号层数量     | 电源/地耦合  | 串扰风险           | 适用场景                   |
| ------ | -------------- | ------------ | ------------------ | -------------------------- |
| 方案一 | 1 个主信号层   | ✅ 紧密耦合   | 低                 | 对信号完整性要求高         |
| 方案二 | 2 个信号层     | ❌ 耦合不充分 | 较高（信号层相邻） | 布线密度大、成本敏感       |
| 方案三 | 1 个高速信号层 | ✅ 充分耦合   | 低                 | 高速信号传输、抗干扰要求高 |
| 方案四 | 2 个信号层     | ✅ 较好       | 中等               | 综合布线与成本折中         |

> **设计建议：** 优先选择信号层与内电层交替排布的叠层方式，确保关键信号层有完整的参考平面，电源层和地层尽量相邻以获得良好的去耦效果。

## 4.逻辑派设置层数

- 逻辑派采用方案2；
- 在层数设置中将层数设成6，并将其重命名为对应层即可；

# 第十一讲：了解阻抗

## 1.什么是阻抗？

### 1.1 定义

在高速数字/射频电路里，**"阻抗"不是电阻**，而是传输线对信号呈现的**交流阻抗**，学名 **特性阻抗（Characteristic Impedance）**，单位 Ω。

- 低频时：导线 ≈ 理想导体，只看电阻
- 高频时：导线变成**传输线**，存在分布电感 L 和分布电容 C
- 信号沿走线传播时，看到的瞬时阻抗就是：

$$Z_0 = \sqrt{\frac{L}{C}}$$

### 1.2 常见目标值

| 类型     | 常见阻抗值       | 典型应用                  |
| :------- | :--------------- | :------------------------ |
| 单端信号 | **50 Ω**         | 绝大多数高速单端信号      |
| 差分信号 | **90 Ω / 100 Ω** | USB、PCIe、HDMI、以太网等 |

> 💡 阻抗由"线宽 + 线厚 + 介质厚度 + 介电常数 Dk"决定，**和走线长度无关**。

## 2.阻抗的来源是什么？

阻抗的来源，本质上是**电磁场在传输介质中的分布**。

在低速时，我们认为电线就是"电阻"，电流流过会发热（欧姆定律）。但在高速时，电信号（本质上是电磁波）在 PCB 走线上传播，会遇到两个关键物理量：

1. **分布电感 (L)**：走线本身具有电感
2. **分布电容 (C)**：走线与参考平面（地/电源）、走线与走线之间都存在电容

**特性阻抗 (Z₀)** 就是由这两个分布参数决定的：

$$Z_0 = \sqrt{\frac{L}{C}}$$

- **它不是电阻**：电阻消耗能量（发热），而阻抗不消耗能量，它只是阻碍电磁波的"瞬时阻力"
- **它只与几何结构有关**：走线的宽度、厚度、与参考层的距离、板材的介电常数，决定了 L 和 C 的大小，从而决定了 Z₀
- **它与走线长度无关**：一条 1cm 的 50Ω 线和一条 10cm 的 50Ω 线，其特性阻抗都是 50Ω

> **通俗理解**：就像水在水管里流，水管越细、水压变化越快，水流遇到的"阻力感"就越强。这个"阻力感"就是阻抗。

## 3.什么是阻抗匹配？

### 3.1 阻抗匹配

**阻抗匹配 = 源端、传输线、负载端阻抗相等**

理想情况：

$$Z_{source} = Z_0 = Z_{load}$$

作用只有一个：**让信号能量被负载吸收，而不是反射回去**。

### 3.2 不匹配会怎样

- 信号反射 → 振铃（ringing）
- 边沿过冲 / 下冲
- 眼图闭合
- 误码率上升
- EMI 变差

### 3.3 反射的物理本质

想象你在玩"甩鞭子"的游戏：
- **匹配情况**：鞭子甩到墙壁，墙壁柔软（阻抗匹配），鞭子的能量被墙壁吸收了，没有反弹
- **不匹配情况**：鞭子甩到水泥墙（阻抗极大），鞭子的能量撞上去弹回来了，形成回响（反射波）

在电路中：
1. 信号从芯片（源端）发出，以电磁波形式在走线上跑
2. 当它到达负载端（接收芯片）时，如果负载阻抗 ≠ 走线阻抗，一部分能量就会**反射**回源端
3. 反射波回到源端，如果源端也不匹配，又会再次反射向负载端……
4. 这种**多次反射**会导致信号波形叠加、变形，产生振铃、过冲、下冲，最终导致逻辑误判或系统崩溃

## 4.为什么低速 PCB 不考虑阻抗匹配

低速 PCB 不考虑，是因为**"反射来不及发生，或者发生了也看不见"**。

### 4.1 黄金法则

传输线效应是否显著，取决于**信号的上升时间 (Tr)** 和**传输线的往返时间 (Td)**。

当 `Tr < 2 * Td`（信号上升时间小于传输线往返时间的 2 倍）时，就必须考虑阻抗匹配。

- **低速信号**：上升时间很长（比如 > 10ns），信号在一个"台阶"还没爬完时，反射波就已经回来了。反射波和原信号混在一起，你肉眼看波形只是幅度稍微变了一点，没有明显的振铃，不影响逻辑判断
- **高速信号**：上升时间极短（比如 < 1ns），信号瞬间就到了高电平。这时候反射波回来时，原信号早就稳定了。反射波会在高电平上"敲鼓"，形成明显的振铃，直接破坏时序

### 4.2 实例计算

FR4 板材上信号速度约 15cm/ns：
- 走线长 5cm → 往返时间 Td ≈ 0.67ns
- 如果信号上升时间 Tr > 1.34ns（对应频率 < ~300MHz），通常可视为低速，忽略匹配
- 如果 Tr = 0.5ns，那就必须严格匹配

> **总结**：低速电路属于"集总参数系统"，导线只是导线；高速电路属于"分布参数系统"，导线变成了"传输线"。

## 5.集总参数 vs 分布参数（深层原理）

本质标准：物理尺寸 vs 波长 (λ)

这是电磁场理论中的绝对标准。

### 5.1 集总参数系统 (Lumped System)

- **条件**：电路的物理尺寸 $L$ **远小于** 信号最高频率对应的波长 $\lambda$
- **数学表达**：$L \ll \frac{\lambda}{10}$（通常取 1/10 作为界限）
- **含义**：信号在电路中传播的时间极短，整个电路可以被视为"一个点"。电压和电流只是时间的函数，与空间位置无关
- **类比**：就像你站在操场一端喊话，声音瞬间传遍全场，你感觉是整个操场在同时震动

### 5.2 分布参数系统 (Distributed System)

- **条件**：电路的物理尺寸 $L$ **接近或大于** 信号最高频率对应的波长 $\lambda$
- **数学表达**：$L \ge \frac{\lambda}{10}$
- **含义**：信号在电路中传播需要时间，不同位置的电压/电流在同一时刻是不同的。电路的特性必须用空间坐标来描述（即存在分布电容、电感、电阻、电导）
- **类比**：就像你在很长的火车车厢里喊话，声音从第一节传到最后一节需要时间，你会看到前面的人先听到，后面的人后听到

### 5.3 为什么"低速"对应"集总"，"高速"对应"分布"

因为**信号的频率决定了波长，而波长决定了电路尺寸是否能被忽略**。

| 场景      | 频率  | 波长 (FR4 中) | 走线 10cm 对比      | 参数类型     |
| :-------- | :---- | :------------ | :------------------ | :----------- |
| 低频/低速 | 1 MHz | ~150 cm       | 10cm ≪ 15cm (λ/10)  | **集总参数** |
| 高频/高速 | 1 GHz | ~15 cm        | 10cm ≥ 1.5cm (λ/10) | **分布参数** |

### 5.4 工程上的"上升时间"判据

这是一个**由波长推导出来的实用公式**：

1. 信号的上升时间 $t_r$ 和信号带宽 $BW$ 有关系：$BW \approx \frac{0.35}{t_r}$
2. 信号的最高有效频率分量 $f_{max} \approx BW$
3. 信号在介质中的传播速度 $v_p \approx \frac{c}{\sqrt{\epsilon_r}}$
4. 走线长度为 $L$ 时，单程延迟 $T_d = \frac{L}{v_p}$

**关键的工程经验法则**：当信号的上升时间 $t_r$ 小于信号在走线上往返一次的时间 $2T_d$ 时，反射效应就会变得明显。

即：**$t_r < 2T_d$** → 分布式系统

这个公式本质上等价于 **$L > \frac{\lambda}{10}$**。

### 5.4 两个判据的统一

| 判据类型            | 物理意义             | 数学条件                                                 | 适用场景             |
| :------------------ | :------------------- | :------------------------------------------------------- | :------------------- |
| **本质判据 (理论)** | 电路尺寸 vs 波长     | $L \ll \lambda/10$（集总）<br>$L \ge \lambda/10$（分布） | 理论分析、射频、微波 |
| **工程判据 (实用)** | 上升时间 vs 传输延迟 | $t_r \ge 2T_d$（集总）<br>$t_r < 2T_d$（分布）           | 数字电路、PCB 设计   |

> **它们说的是同一件事！**
> - "低速" = "波长很长" = "上升时间很长" = "电路尺寸远小于波长" = **集总参数**
> - "高速" = "波长很短" = "上升时间很短" = "电路尺寸接近波长" = **分布参数**

## 6.单端信号 vs 差分信号

这是两种完全不同的传输机制，阻抗的定义和匹配策略也不同。

### 6.1 核心区别对比

| 维度           | **单端信号 (Single-Ended)**                                  | **差分信号 (Differential)**                                  |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **定义**       | **一根信号线** + 参考地（GND/VCC）。信号值是信号线对地的电压 | **两根信号线** (P 和 N)。信号值是两根线之间的电压差 (V_P - V_N) |
| **阻抗定义**   | **单端阻抗**：信号线对参考平面的阻抗。常见 **50Ω**           | **差分阻抗**：两根线之间的阻抗。常见 **90Ω** (PCIe) 或 **100Ω** (USB/Ethernet) |
| **抗干扰**     | 弱。地电位波动、电磁干扰直接叠加在信号上                     | **极强**。干扰同时作用在两根线上，接收端相减后抵消（共模抑制） |
| **辐射/EMI**   | 大。电流一去一回，磁场向外辐射                               | 小。两根线电流方向相反，磁场相互抵消                         |
| **匹配策略**   | 只需匹配信号线对地。通常在源端串联电阻（如 22Ω-33Ω）抵消芯片低阻抗 | 必须保持两根线**等长、等宽、等距**，匹配的是差分对整体。通常接收端跨接电阻 |
| **计算复杂度** | 相对简单，只关注线宽、层厚、介电常数                         | 复杂，除了上述参数，还高度依赖**两根线之间的间距 (S)**       |

### 6.2 关键误区：差分阻抗 ≠ 单端阻抗 × 2

实际上：

$$Z_{diff} \approx 2 \times Z_{se} \times (1 - k)$$

其中 $k$ 是耦合系数。当两根线靠得很近（强耦合）时，差分阻抗会明显小于两倍单端阻抗。

这也是为什么做 100Ω 差分对时，单端阻抗通常设计在 50Ω 左右，而不是 100Ω。

## 7.阻抗匹配应该怎么做？

### 7.1 先算准单板阻抗（叠层设计阶段）

不要事后改线，要在**叠层表里定死**：

| 参数           | 影响规律            |
| :------------- | :------------------ |
| 介质厚度 H     | 越厚 → 阻抗越大     |
| 线宽 W         | 越宽 → 阻抗越小     |
| 铜厚 T         | 越厚 → 阻抗略小     |
| Dk（介电常数） | 越大 → 阻抗越小     |
| 差分间距 S     | 越小 → 差分阻抗越低 |

**常用工具**：

- 厂家的阻抗计算表
- Polar SI9000
- KiCad / Altium 自带阻抗计算器

> ⚠️ 实际打样一定要给 PCB 厂 **阻抗控制说明**：哪一层、单端还是差分、目标 Ω、公差 ±10%

### 7.2 走线规则（物理层匹配）

- 走线**等宽、等距、少过孔**
- 差分对：长度匹配（通常 ±5 mil 以内）
- 避免直角（用 45° 或圆弧）
- 参考平面完整（**不要跨分割**）
- 换层必须就近打 GND 过孔（返回路径连续）

### 7.3 端接匹配方式（电路层匹配）

#### ① 源端串联匹配（最常用）

在驱动端串一个电阻 Rs：

```
Driver ──Rs─── Z0 走线 ─── Load
```

- 取值 ≈ $Z_0 - R_{drv}$
- 原理：源端阻抗 + Rs = Z0，负载开路反射被源端吃掉
- 适合：点到点、时钟、单端高速信号

#### ② 终端并联匹配

在接收端对地/对电源接 R = Z0：
- 功耗大，但反射抑制最强
- 适合：总线、多负载

#### ③ 差分匹配

- 差分线两端各加终端电阻（100Ω 跨在 P/N 之间）
- PCIe / USB / LVDS 基本都这么干
- 有时接收端内部已有，外部可省

#### ④ AC 匹配 / 戴维南匹配

- 高频模拟、RF 前端常见
- 用电容隔直 + 电阻网络

## 3.绑定规则

- 先将之前差分对规则里面的100ohm设置成默认，因为所有差分对中除了USB都是100ohm的；
- 然后在网络规则里面把USB的规则改成90ohm的规则；
- 这样设置后，后面我们在走这些差分对的时候它就会自动按照我们规则里面设置的走线；
- 需要注意，在导线中要将50ohm阻抗设置成默认，这样其他线才会走50ohm阻抗，这样的话基本所有网络我们都完成规则绑定了；

![绑定规则](.\img\第十四讲：差分规则的添加\绑定规则.png)

# 第十五讲：BGA扇孔以及BGA滤波电容摆放

## 1.FPGA扇孔

- 选中FPGA，然后右键，扇出布线，选择新增，然后其他保持默认即可完成扇孔；

## 2.滤波电容布局

- 1.0V的滤波电容布局
  - 1.0V的滤波电容一共6组，分别是一个大电容一个小电容，先在BGA的四个顶点各放一组；
  - 接着把剩下的两组放到BGA内部的1.0V对应的引脚附近，如果扇孔位置不合适就调整扇孔的位置；
- VCCPLLL的滤波电容布局
  - 一共4个元件，将一个小的电容放到引脚，剩下的3个先放到旁边的空余位置；
- VCCPLLR的滤波电容布局
  - 一共4个元件，将一个小的电容放到引脚，剩下的3个先放到下面晶振区域；
- 3.3V的滤波电容布局
  - 在原理图中，3.3V的滤波电容是有对应不同的Bank的，需要找到对应Bank的引脚放置在其旁边（Bank0、Bank1、Bank2&3）；
  - 但每个Bank的滤波电容都是100nF，随便放也无妨；
  - 最后4个3.3V的大电容先放在中间过道上，VCCPLLL的那3个电容先放到右上角；
- 1.5V的滤波电容布局
  - 同样的，摆放在引脚旁边，都是100nF的，不太需要注意Bank的问题；

## 3.BGA外沿两排的扇出

- 虽然BGA芯片的顶层已经没有办法走线了，但是可以把它扇出到外面，这样其他信号层就可以走更多的线了；
- 先将独立对象仅选择过孔和走线，然后将左下角中心往外的6列拉出来，增加内层走线；
